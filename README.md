# 🎓 EduTrack — Smart School Management Platform

**EduTrack** is a digital school management platform designed to help students, teachers, and school administrators manage academic activities more efficiently.

## 🚀 Project Overview

EduTrack brings important school activities together in one platform, making it easier to organize assignments, monitor academic performance, manage attendance, and communicate school announcements.

## ✨ Main Features

### 👨‍🎓 Student Dashboard
- View assignments and deadlines.
- Check academic results.
- Monitor attendance.
- Receive school announcements.
- Track academic progress.

### 👩‍🏫 Teacher Dashboard
- Create and manage assignments.
- Enter student marks.
- Record attendance.
- Monitor student performance.

### 🏫 Administrator Dashboard
- Register students and teachers.
- Manage classes.
- Publish school announcements.
- View school information.

## 📊 Academic Analytics

Planned enhancements include:
- Academic performance graphs.
- Subject comparison charts.
- Attendance statistics.
- Performance prediction scenarios.
- Academic improvement recommendations.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

## 💾 Data Storage

The current demonstration version uses browser Local Storage to retain information on the same browser and device. It does not yet use a shared online database.

## 🎯 Project Goal

To provide a simple and accessible digital platform that supports communication, assignment management, and academic progress monitoring in schools.
